% BEGIN PROFESSOR FEEDBACK PF31: Outlook - Temporal order and network null model
A further experiment should separate temporal order from graph structure more
directly. The current role catalogue combines direction, local node position,
topology, and event order. It can show that the complete fingerprint is useful,
but not how much of that usefulness comes from the order alone. Comparing it
with an otherwise identical unordered representation would help isolate the
contribution of temporal ordering. A separate random-network comparison could
shuffle timestamps while retaining the directed transfers, then compare the
candidate counts with their reference distributions. That experiment would test
overrepresentation conditional on the preserved graph structure, with correction
for the number of tested patterns and windows.
