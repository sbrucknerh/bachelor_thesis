\section{Limitations}

\paragraph{Candidate patterns and network significance.}
The experiments count candidate temporal subgraphs and evaluate their local
role fingerprints as predictive features. No random-network reference is
generated, so the study cannot establish that any individual pattern is a
statistically overrepresented network motif. Synthetic templates validate the
counter, and prediction permutations test classification results. Neither
replaces a network null model.
